# 30-Day Launch Action Checklist

## Days 1-7: Foundation ✅

### Menu & Pricing
- [ ] Select 6-8 dishes for initial menu
- [ ] Calculate ingredient costs for each dish
- [ ] Set selling prices (ingredient cost × 2.5-3.0)
- [ ] Create menu document (PDF/image)
- [ ] Decide on upsell items (drinks, sides)

### Suppliers
- [ ] Research and contact primary suppliers
- [ ] Get quotes from 2-3 suppliers per major ingredient
- [ ] Choose primary and backup suppliers
- [ ] Create supplier contact list
- [ ] Test order from suppliers

### Legal & Setup
- [ ] Contact local council about food business registration
- [ ] Enroll in food hygiene course (Level 2)
- [ ] Get insurance quotes (public liability)
- [ ] Prepare kitchen for inspection
- [ ] Document allergen information for all dishes
- [ ] Decide on location (home kitchen/stall/etc.)

### Operations
- [ ] Set opening hours
- [ ] Create food safety checklist
- [ ] Plan storage space (cooler, dry storage)
- [ ] Set reorder levels for ingredients

---

## Days 8-14: Testing ✅

### Cooking & Quality
- [ ] Test cook all menu items
- [ ] Document recipes with exact measurements
- [ ] Test portion sizes (use scales)
- [ ] Conduct taste tests with 5-10 friends/family
- [ ] Collect feedback and adjust recipes
- [ ] Create recipe cards for consistency

### Packaging
- [ ] Research packaging options (3 different types)
- [ ] Order samples of packaging
- [ ] Test packaging for:
  - [ ] Leak-proof
  - [ ] Heat retention
  - [ ] Appearance
  - [ ] Cost
- [ ] Choose final packaging option
- [ ] Order initial packaging supply

### Branding
- [ ] Use official company logo from IMG_2553.png for all branding
- [ ] Design labels/stickers using the official logo (two chefs with Gambian flag)
- [ ] Include: logo, dish name, date, reheating instructions
- [ ] Order labels/stickers
- [ ] Take 6+ food photos (natural light)
- [ ] Edit photos for social media (include logo watermark/branding)

### Systems
- [ ] Set up dedicated phone/WhatsApp for orders
- [ ] Create order tracking system (spreadsheet)
- [ ] Create financial tracking spreadsheet
- [ ] Test order flow (practice with friends)
- [ ] Set up payment methods (cash, bank transfer, etc.)

---

## Days 15-21: Soft Launch ✅

### Marketing Setup
- [ ] Create Facebook business page (use official logo from IMG_2553.png as profile picture)
- [ ] Create Instagram business account (use official logo from IMG_2553.png as profile picture)
- [ ] Post initial content (logo, menu, food photos)
- [ ] Join local food groups on Facebook
- [ ] Create WhatsApp broadcast list (use logo in profile)
- [ ] Design launch promotion offer

### Soft Launch
- [ ] Announce soft launch to friends/family
- [ ] Take first 5-10 orders from friends
- [ ] Test full workflow:
  - [ ] Order taking
  - [ ] Cooking
  - [ ] Packaging
  - [ ] Delivery/pickup
  - [ ] Payment collection
- [ ] Collect detailed feedback
- [ ] Take photos of actual orders
- [ ] Refine processes based on feedback

### Quality Control
- [ ] Implement "taste day" schedule
- [ ] Create feedback collection system
- [ ] Set up complaint handling process
- [ ] Document any issues and solutions

---

## Days 22-30: Full Launch ✅

### Pre-Launch
- [ ] Finalize all systems and processes
- [ ] Stock up on ingredients and packaging
- [ ] Prepare launch marketing materials
- [ ] Set daily sales targets
- [ ] Review and adjust prices if needed

### Launch Week
- [ ] Announce official launch on social media
- [ ] Post launch deal/promotion
- [ ] Share in local groups
- [ ] Start taking orders from wider audience
- [ ] Post regularly (3x/week minimum)

### Operations
- [ ] Track daily sales and expenses
- [ ] Collect customer reviews
- [ ] Ask every customer for feedback
- [ ] Monitor social media for mentions
- [ ] Respond to all messages promptly

### Review & Adjust
- [ ] Review first week's finances
- [ ] Calculate break-even progress
- [ ] Identify top-selling dishes
- [ ] Note common customer requests
- [ ] Plan improvements for month 2
- [ ] Celebrate first successful week! 🎉

---

## Daily Tasks (Ongoing)

- [ ] Check and respond to orders (phone/WhatsApp)
- [ ] Update order tracking spreadsheet
- [ ] Update financial tracking spreadsheet
- [ ] Post on social media (if scheduled)
- [ ] Collect customer feedback
- [ ] Review food quality (taste day once per week)
- [ ] Check ingredient stock levels
- [ ] Plan next day's prep

---

## Weekly Tasks

- [ ] Review weekly sales vs target
- [ ] Review customer feedback log
- [ ] Taste day - quality check all dishes
- [ ] Plan social media content for next week
- [ ] Review and adjust menu if needed
- [ ] Check supplier orders and reorder if needed

---

## Monthly Tasks

- [ ] Review monthly financials
- [ ] Calculate profit/loss
- [ ] Review customer feedback trends
- [ ] Plan menu additions/changes
- [ ] Review and adjust prices if needed
- [ ] Plan marketing for next month
- [ ] Review and update business plan

---

**Tips:**
- Don't try to do everything perfectly - start simple and improve
- Focus on quality and consistency over quantity
- Customer feedback is gold - listen and adapt
- Track everything from day one - it will help later
- Celebrate small wins along the way!
