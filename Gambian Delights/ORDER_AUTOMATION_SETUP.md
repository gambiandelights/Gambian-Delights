# Order Automation Setup Guide

## Current System
Orders are currently sent via email (mailto links) which requires manual handling.

## Recommended Solution: Formspree

### Why Formspree?
- ✅ Free tier: 50 submissions/month
- ✅ Automatic email notifications
- ✅ No backend/server needed
- ✅ Easy to set up
- ✅ Professional appearance
- ✅ Can upgrade later if needed

### Setup Steps:

1. **Create Formspree Account**
   - Go to: https://formspree.io
   - Sign up for free account
   - Create a new form
   - Copy your form endpoint (looks like: `https://formspree.io/f/YOUR_FORM_ID`)

2. **Update Website**
   - Replace email submission with Formspree endpoint
   - Orders will automatically be sent to your email
   - You'll receive notifications instantly

3. **Alternative: EmailJS (If Formspree doesn't work)**
   - Go to: https://www.emailjs.com
   - Free tier: 200 emails/month
   - Connect to your Gmail account
   - Get API keys and update website
